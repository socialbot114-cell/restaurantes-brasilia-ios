# Suporte — Restaurantes Brasília

Para pedir ajuda, relatar um erro ou solicitar uma correção no catálogo, abra
uma solicitação no [rastreador público do projeto](https://github.com/socialbot114-cell/restaurantes-brasilia-ios/issues).

Inclua o modelo do aparelho, a versão do iOS e os passos para reproduzir o
problema. Não publique telefone, endereço residencial, credenciais ou outros
dados pessoais em uma solicitação pública.
